## 额外业务与安全覆盖

- 北京时间跨日/跨周切分、一个活动计时限制、重复点击、补录未来/重叠拒绝。
- 连续学习 35 天不会被 28 天分析窗口截断；删除一天后正确停止连续天数；当天尚未学习时延续昨天的记录。
- 目标/优先级、版本冲突、知识父子循环和引用删除保护、v1 到 v3 保留 IDs/关系。
- 真实错题创建/删除事件构成数量趋势，不把当前总量伪造为历史。
- Cookie 会话失效、写入来源防护、错误令牌限流、密钥不进入导出和响应。
- 路径穿越归档、错误表结构、错误 JSON 拒绝；恢复异常/进程中断不会留下混合数据库与附件。
- 实际文字 PDF 与无文本层 PDF、非法图片拒绝、附件引用保护、本地算式不执行任意代码。
- PWA 离线页可见、API 不进入缓存、资料和备份按钮实际工作。
