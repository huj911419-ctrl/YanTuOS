# 使用说明

## 一天的学习闭环

1. 每日计划中创建一个可检查的任务，例如「理解导数定义并独立完成 5 道基础题」。选科目、优先级、预计时长，可关联阶段目标。
2. 开始专注计时。暂时离开时暂停；结束后写学习小结。关闭页面不会结束正向计时；番茄钟即使关闭页面也只累计预定时长，重新请求服务时会按准确截止时间落库。
3. 遇到不会独立完成的题，录入错题、自己的答案、正确答案和错因，关联知识点。可上传最多 10 张 PNG/JPEG/WebP，每个文件不超过 20 MB；HEIC 需先转换。
4. 复习先独立尝试，再看答案。如实选择独立完成、提示后完成或未掌握，不要用“看懂了解答”代替独立能力。
5. 查看学习统计与规则建议，调整下一天的计划。统计中的时长是投入记录，不是能力分数。

## 计划与知识库

「每日计划」看单日；「周计划与目标」按选定起点看连续七日，也能查全部历史或未完成任务。目标完成由自己确认，关联任务完成数由数据库计算。

知识点的“知识分类”就是章节，科目和章节一致才能选择父知识点。禁止层级循环；被错题、子知识点或资料引用时，需先解除/调整关联才能删除。原始参考目录可修改，不代表任何年份的最终大纲。数学一/二/三是个人标注标签；资料来源和适用年份由你记录。

掌握程度是 0–5 的个人记录。知识点复习中独立完成 +1、未掌握 −1、提示后不变；结果限定在 0–5。规则不能证明已经达到考研成绩要求。

## 计时、补录与更正

同一时刻只允许一个活动计时。暂停时间不算学习；正向计时跨午夜会按北京时间拆分统计。番茄钟默认 25 分钟，可配置；到时后台按目标总时长封顶。休息需主动开始，页面显示休息结束时间，不计入学习时长；不保证 iPhone 后台响铃。

补录填写北京时间、开始时间与分钟数。不接受未来或与现有片段重叠的时间。更正记录会把原来的暂停片段替换为连续时段，界面会说明；删除已结束记录会同步改变统计。

## 复习规则

默认间隔 1、3、7、14、30 天，设置中可修改为五个严格递增的 1–365 天值。新错题按首个间隔安排；独立完成推进一阶段，第五次完成本轮；未掌握重置并按首个间隔安排；提示后不推进，次日再练。逾期按实际复习日计算下一次日期，不重复堆积过期任务。当天重复提交会被拒绝。

知识点首次间隔由掌握程度选择，关联错题越多，首次间隔越短。生成操作不会推迟已经存在的安排；可在复习详情中手动调整日期。手动将错题标为掌握会结束本轮安排，改回未掌握可再次开始。

## 资料、AI 与离线

资料支持 UTF-8 TXT/Markdown 与 PDF。PDF 文本提取最多前 50 页、约 50 万字符，并有 CPU/内存/时间限制。加密、扫描或复杂 PDF 可能无法提取，但原文件仍可下载。内容以安全的纯文本显示，不执行 HTML。

AI 页面以任务类型选择概念解释、题目解析、错因分析、练习、每日/每周建议或总结。未配置时不会生成假回复。配置后先预览消息、目标和历史，再明确授权。结果保存在本地，数学结论仍需检查；本地数值核对只支持有限算术，不能检验证明题。

“没有模型 API 可用”与“无法连接 Ubuntu”不同：前者所有基础功能正常；后者仅有 PWA 离线说明页，不能新增任务或控制服务端计时，不做离线写入合并。
