# 常见问题与故障定位

## 无法打开页面

执行 `./scripts/status.sh`、`./scripts/doctor.sh`。本机默认 `http://127.0.0.1:8000`。若未运行，执行 `./scripts/start.sh`；若端口被占用，脚本会拒绝启动，不会终止其他程序。检查自己的旧前台进程或更换 `.env` 的 `YANTU_PORT`，并相应更新允许的来源。

## 服务启动失败

查看 `.runtime/logs/server.log`。缺依赖运行 `./scripts/setup.sh`；缺前端构建运行 `./scripts/build.sh`。不删除数据库来“修复”。若数据库版本高于程序，使用匹配的新程序；若迁移失败，原始快照在数据目录的 `backups/`，使用隔离恢复。

## 启动脚本说已运行，但没有响应

执行 doctor。脚本只凭自己的 PID、进程启动时刻和完整命令核验归属；不会用通用 `pkill`。确认后用 stop/start 重启。健康检查失败时也可能是 HTTPS 的 CA 或访问 IP 不匹配，不要直接关闭证书验证。

## 手机上访问失败

检查同一网络、Ubuntu 是否休眠、IP 是否变动、服务是否绑定该私有 IP、HTTPS 证书是否匹配且已由你信任、允许的 Host/Origin 是否包含该地址。软件不会替你修改防火墙。不要把 `0.0.0.0`、公网 IP 或通配来源当作排错捷径。

## 登录失效

会话最长 24 小时；重启服务会清除会话。重新输入 `.env` 中的访问令牌。五分钟内连续 10 次错误会暂时限流。令牌不能通过 URL 传递；.env 真实内容不要发到公共 Issue。

## 为什么保存时提示记录已修改

任务、知识点和错题编辑使用版本检查，防止两个设备互相覆盖。刷新并重新编辑；原编辑内容会留在未关闭表单里，先自行复制保存。

## 时间看起来过长

正向计时不会因关闭页面或服务短暂停机自动结束。结束后可以在「补录与更正」修正记录。番茄钟最多累计目标时长；暂停、休息不计时。日期按北京时间统计，周一开始。

## 图片上传了却没出现在错题里

需要在图片上传完成后保存错题。取消表单会保留未关联附件，可到设置单独确认删除。不要直接删 uploads 文件夹。HEIC 不受支持，请在设备上导出 JPEG。

## JSON 或 SQLite 恢复提示缺附件

它们只含数据库内容，请使用完整 ZIP。恢复预览不修改现有数据。确认恢复后，回滚 ZIP 和旧附件仍被保留；在确定不需要之前不要删除。最大恢复展开大小为 512 MB，超限先整理规模和备份策略。

## 恢复过程中程序意外退出

重新运行 start。应用会读取数据目录的 restore-in-progress.json，从操作前完整快照回滚后再开放 API。不要手动删除中断标记、原快照或旧附件目录；若自动恢复失败，保留现场，查看日志并先使用 restore.sh 恢复到新目录核对。

## PDF 提取不到文字

扫描版没有文本层，当前未提供 OCR；加密/复杂文件也可能提取失败。可下载原文件并手工补充笔记。不会将文件上传到第三方识别服务。

## AI “已配置”却请求失败

“已配置”只代表地址、模型、密钥齐全。检查 Base URL 是否包含正确前缀、模型名称和服务协议。第一适配器调用 `/chat/completions`，使用 `max_tokens` 参数；某些服务只支持其他协议，需要扩展适配器。环境变量优先于设置页。超时不自动重试，避免重复费用；具体计费结果以供应商为准。

## 页面版本未更新

重新构建并重启。若页面提示有新版本，先保存表单再点击更新。Service Worker 不缓存 API 响应或私人附件；首次注册不会自动刷新表单。

## 浏览器测试缺依赖

先安装 Playwright 的 Chromium/WebKit 浏览器；Ubuntu 26.04 的本地 WebKit 库见 README。项目包装脚本校验实际动态库，再处理 Playwright 仅查看系统缓存的预检限制；没有跳过业务断言。测试报告中明确列出跳过项，不把 WebKit 模拟当作 iPhone 真机。

## 未来没有 AI，如何继续维护

保存整个源码、锁文件、README 和完整 ZIP 备份。启动只需 Python 虚拟环境；修改前备份，修改后跑 `./scripts/test.sh`，再构建重启。遇到问题记录日志中的错误编号、动作、软件版本；提交 Issue 前去除密钥和私人数据。
