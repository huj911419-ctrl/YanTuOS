# 长期路线图

## 0.1 原 MVP（已验收）

日任务、可恢复正向计时、基础知识参考目录、手工错题、错题间隔复习、真实统计、JSON/SQLite 导出。

## 0.2 个人学习平台（当前交付）

任务优先级/目标/周计划、番茄钟和补录、知识层级与知识复习、错题图片/分类/错误答案、范围统计与规则建议、可替换 AI 协议与授权预览、资料管理、认证、PWA 离线说明、完整备份和安全恢复、进程脚本和独立维护文档。实际验证状态以 FEATURE_STATUS 与 TEST_REPORT 为准。

## 外部条件验收

- 用户自己的 iPhone：HTTPS 根证书信任、Safari/主屏幕安装、真实网络和后台使用。
- 用户明确授权的模型：供应商协议、实际模型答案质量、使用费用和真实超时行为。
- 数学类别确定后：按有明确来源与年份的官方资料核对知识范围；不提前固化。

## 后续可选改进

- 大规模记录的服务端分页、查询优化与更多长期趋势图。
- 经独立练习结果校准的知识掌握模型；先积累真实数据再评价算法。
- 经授权的图片理解、OCR、公式排版与更丰富的数学工具验证。
- 新模型协议适配器、可审阅的结构化计划采纳流程。
- 真机验证后的通知体验；离线可编辑同步另行设计冲突策略，当前不承诺。
- 如出现多用户或远程托管需求，再单独设计身份、权限、TLS 运维和数据库部署，不能直接把个人服务开放到公网。
