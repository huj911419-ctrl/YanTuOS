# 技术决策

## 2026-10-17 · 第一阶段

1. **React + TypeScript + Vite / FastAPI / SQLite**：采用用户建议。单用户场景无需服务器数据库；生产只跑一个 Python 进程。选择已有稳定版本系列，并保存实际安装锁文件。
2. **Python 标准库 sqlite3**：当前表关系简单，显式参数化 SQL 易于学习、备份与维护，暂不引入 ORM。数据库访问集中在后端，未来迁移时替换此层。
3. **原生 CSS + Lucide 图标**：不引入大型组件框架；中文优先，低干扰的绿色学习空间。无外部字体或分析追踪脚本。
4. **分段计时**：暂停关闭片段，继续开启新片段；学习总时长是片段和。跨日按片段和日期窗口求交集，服务重启不会重置计时。
5. **统一上海时区**：实际时间存 UTC，任务、复习、统计日界用 Asia/Shanghai。周一作为周起点。目标月份并非官方考试日期。
6. **不锁定数学类别**：初始化 21 个基础参考知识点，四类状态由本人确认。没有预设最终大纲、分数或机器诊断。
7. **规则复习**：首次次日；记住后依次 3/7/14/30 天，5 次连续记住结束，失败次日重新开始。次数与历史分别存表；到期前仅预览。
8. **AI 默认禁用**：保留服务协议与 HTTP 503，不因存在配置名称或占位密钥就声称可用。MVP 不发送任何学习内容至模型 API。
9. **保护既有内容**：创建前确认目标目录不存在；没有删除旧项目。测试数据库全部隔离。恢复拒绝覆盖文件，删除记录需在界面确认。
10. **本机部署**：默认 loopback，不创建公网映射。手动局域网启动必须显式配置主机、来源和至少 16 字符令牌；首版没有替用户执行。
11. **pnpm 11.25 与已有工具链**：系统没有 Node/npm，复用了 Codex 配套 Node 24.19 与 pnpm 11.25，脚本可检测回退；不安装系统包。只允许 esbuild 构建脚本，修复 pnpm 新版本构建配置变化。
12. **数据可迁移**：提供 JSON 全表导出和在线 SQLite 快照；恢复新路径后通过环境变量切换，保留原文件。首版没有危险的在线覆盖导入。
13. **MIT 许可**：便于个人项目开源与后续贡献。只初始化本地 Git，不创建或推送远程仓库；学习数据与密钥默认忽略。
14. **无特权的 WebKit 测试环境**：这台 Ubuntu 缺少部分浏览器库，使用官方 apt 源下载 `.deb` 并解包到被忽略的 `.runtime/`，不运行 sudo、不安装系统包。通过真实动态加载验证必需库；专用启动脚本保留库路径，解决上游包装脚本重置该变量的问题。仅在使用私有库时绕过不能识别私有目录的系统缓存环境检查，仍运行完整 WebKit 实际操作。浏览器测试显式绕过桌面代理的本机流量。

依赖说明参考：[Vite 官方环境要求](https://vite.dev/guide/)、[FastAPI 数据库说明](https://fastapi.tiangolo.com/tutorial/sql-databases/)、[pnpm 11 构建设置变化](https://pnpm.io/blog/releases/11.0)。

## V2 决策（2026-10-17）

- 沿用现有 React/FastAPI/sqlite3，不引入 ORM 重写、微服务或独立数据库服务。迁移增加新表与字段，保留 IDs。
- 科目与章节保持轻量：科目有管理表，章节作为知识点 domain，parent_id 表示子知识点；不导入未经核实的官方考纲。
- 计时以服务端片段为准；番茄钟采用请求时结算，截止时间不随页面关闭而延长。休息主动开始，不承诺 iOS 后台通知。
- 透明复习规则固定五阶段，天数可配置。知识点分数只是自评/规则记录，不预测考试成绩。
- 补录和更正拒绝与已有片段重叠；更正将原片段替换为连续记录，界面明确提示。
- AI 适配器先使用文本 Chat Completions 协议；不给默认商业模型，不提供假回复，不自动试连/重试。服务切换和每次消息范围通过可见预览确认。参考官方 Chat Completions 文档，由 OpenAI Docs 技能核对协议。
- 数学交叉检查只实现有长度/运算限制的数值 AST 解释器，不执行 eval、模型代码或任意符号表达式。
- 文件保存在数据库旁的 uploads；PDF 使用 pypdf 子进程受限提取，图像仅使用 Pillow 校验，不安装 OCR 或重型资料服务。
- 全量备份采用 ZIP + SQLite 快照 + SHA-256。恢复默认隔离；页面覆盖需要明确文字确认并保存回滚快照。加入中断标记与启动自动回滚，防止附件/数据库切换到一半。
- 手机采用同一响应式前端；完整 PWA 要求受信任 HTTPS。证书生成限项目目录，信任操作由用户完成，不修改系统安全配置。
- API key 只读取环境变量；访问认证使用内存会话、HttpOnly Cookie 和单用户令牌。未启用令牌时拒绝非本机 API 请求。
- 不配置虚构 Git 作者身份；未配置身份时保留代码与状态文档，交由维护者用自己的身份提交。不推送远程。

- 连续学习天数基于全部真实计时片段，28天仅限制分析窗口；当天尚未学习时以昨天为连续终点。测试覆盖35天及中断边界。
